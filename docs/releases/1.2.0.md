# TPF2 Multiplayer Launcher 1.2.0

- Remove multiplayer: the new **Remove multiplayer** button under "Your game" uninstalls the mod and restores the original game files. The current mod files are backed up first. Saves, other mods and backups are kept.
- Installing an older version is easier to find: **Install a different version** below the play buttons opens the release history.
- Visible progress: the main button now shows each step with a progress bar, for example "Downloading release… 52%", "Unpacking release…" and "Installing release…".
- A calmer installation panel: the status line is smaller and only appears when there is something to report.

## Update

Check for launcher updates in Settings, or download and run `TPF2-Multiplayer-Launcher-1.2.0-Setup.exe`.
Close the game before installing updates.
