# TPF2 Multiplayer Launcher 1.0.1

Fixes newer multiplayer releases such as `v0.7` not appearing in the launcher.

- Show the most recently published release in the selected Stable or Experimental track, regardless of its version name.
- Keep releases visible in the main view and history when their package cannot be installed, with an explanation instead of silently hiding them.
- Support two-part versions such as `0.7` alongside existing three- and four-part versions.
- Accept equivalent MSI versions with trailing zeroes, such as release `0.7` and installer `0.7.0`, while retaining source, checksum and product verification.

## Update

In launcher 1.0.0, open Settings, check for launcher updates and install 1.0.1.
Alternatively, download `TPF2-Multiplayer-Launcher-1.0.1-Setup.exe` from this release and run it.

This update fixes release discovery and version matching. It does not change the multiplayer mod itself. Close the game before installing updates.
