# TPF2 Multiplayer Launcher 1.0.0

First release in the dedicated `tpf-multiplayer-launcher` repository.

- Install, update and play Silver's multiplayer mod for Transport Fever 2.
- Choose Stable or Experimental releases and browse previous versions.
- Verify downloads and retain configurable backups for recovery.
- Read the original GitHub release notes directly in the launcher.
- Automatically check for launcher updates on startup. A highlighted button
  in the top-right corner shows the new version and opens Settings.
- Fill the entire window with the city background while keeping content centered.

## Installation

Download `TPF2-Multiplayer-Launcher-1.0.0-Setup.exe` and run it. The installer
installs for the current Windows user and installs WebView2 if needed.

Requires Windows 10/11 x64, Steam and Transport Fever 2 Steam build 35924.
Close the game before installing updates. Everyone in a multiplayer session
must use the same mod version.

This repository starts its own version and signed update feed at 1.0.0.
Install this version manually when moving from the old repository's 2.x builds.
Launcher updates require an explicit click to install. Updater packages are
cryptographically signed; the Windows installer has no Authenticode certificate.
