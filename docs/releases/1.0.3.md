# TPF2 Multiplayer Launcher 1.0.3

- Fix stale installed-version and Play indicators after uninstalling or reinstalling Transport Fever 2. Check the mod files and loader in the selected game folder instead of relying only on a saved profile or registry entry.
- Allow multiplayer to be installed again when its files are missing, including when the selected release matches the previously installed version.
- Fix installation error 1603 when upgrading an older registered mod after a Steam reinstall. Preserve the verified original audio DLL before the old MSI removes the loader.
- Explain when the original audio DLL is missing or modified and Steam file verification is required before installation.

## Update

Check for launcher updates in Settings, or download and run `TPF2-Multiplayer-Launcher-1.0.3-Setup.exe`.
Close the game before installing updates.
