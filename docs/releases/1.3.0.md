# TPF2 Multiplayer Launcher 1.3.0

- Linux: the launcher now runs on Linux as an AppImage, for the native Linux version of Transport Fever 2 and for the Windows version under Proton. **Game type** in Settings switches between the two (Automatic follows Steam's setting). It installs, updates and removes multiplayer, and repairs the game's start script after Steam restores it.
- New release layout: from TpF2 Multiplayer 0.7.0.6 the release page carries the two launchers, and the install files come from their own release. The launcher finds them in either place and no longer lists launcher updates or duplicate entries as mod versions.

## Update

Check for launcher updates in Settings, or download and run `TPF2-Multiplayer-Launcher-1.3.0-Setup.exe` (Windows) or `TPF2-Multiplayer-Launcher-1.3.0-x86_64.AppImage` (Linux).
Close the game before installing updates.
