# 1.0.2

- Fix installation of multiplayer 0.7 by supporting its bundled Big Maps plugin and configuration. Both files are included in verified profiles, backups and recovery, and removed when switching to an older release without Big Maps.
- Integrate the current operation and download progress into the right-hand installation panel, with readable text and a subtle divider.
- Replace the full-width update-check button with a compact refresh icon beside the installation heading.
- Improve wrapping and readability of status and error messages.

## Update

Check for launcher updates in Settings, or download and run `TPF2-Multiplayer-Launcher-1.0.2-Setup.exe`.
Close the game before installing updates.
