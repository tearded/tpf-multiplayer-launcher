# TPF2 Multiplayer Launcher 1.1.0

- New look: a TF2 MP app icon and the Transport Fever 2 Multiplayer wordmark in the launcher.
- Lower background load while the launcher is open. It now checks whether the game is running without re-reading the mod files every few seconds.
- A background task that stops responding no longer blocks the launcher. It is closed after a time limit with a message, so you can try again.
- The game folder dialog always opens in front of the launcher.
- Installations that need administrator permissions now also work when they are approved with a different Windows account.
- A new installation no longer fails after a previous installation was interrupted by a crash.

## Update

Check for launcher updates in Settings, or download and run `TPF2-Multiplayer-Launcher-1.1.0-Setup.exe`.
Close the game before installing updates.
